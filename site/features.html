What it reports

The useful basics, all in one report.

A focused snapshot printed directly in your terminal by the Python script.

CPU

Processor

Displays the processor identifier provided by Python’s platform information.

02

Cores and threads

Reports physical CPU cores and logical CPU threads when the system provides them.

RAM

Total memory

Shows total system memory in gigabytes using the psutil library.

OS

Operating system

Prints the operating-system name and release reported by the running system.

Straightforward by design

One script. A readable summary.

Python’s built-in platform module supplies processor and operating-system details. The psutil library supplies CPU counts and total memory.

The website does not receive the report. When run in GitHub Actions, the script reports the runner’s environment, not your personal computer.

Example report fields
CPU: processor identifier
CPU Cores: physical core count
CPU Threads: logical processor count
RAM: total memory in GB
Operating System: name and release
