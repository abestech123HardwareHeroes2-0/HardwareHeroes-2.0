Requirements and setup

Get running in three steps.

Hardware Heroes 2.0 is distributed as source code in this repository; it is not currently published as a pip package or installer.

Before you begin

Requirements

Python3.9 or later
Dependencypsutil
InterfaceCommand line

The website does not run the script for you. Use a terminal on the computer you want to inspect.

1

Get the source

Clone the repository and enter its folder.

git clone https://github.com/abestech123HardwareHeroes2-0/HardwareHeroes-2.0.git
cd HardwareHeroes-2.0
2

Install the dependency

Install psutil with the Python interpreter you intend to use.

python -m pip install psutil
3

Run the utility

The report will appear in your terminal.

python detect-hardware.py
Remember

Run it where you want the information from.

Locally, it reports your computer. In GitHub Actions, it reports the hosted runner.
